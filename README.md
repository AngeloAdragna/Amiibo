# Présentation

## Description

Ce projet est une application mobile dont l'objectif est de réaliser un quiz sur les Amiibo dans le cadre de l'unité d'enseignement **Application mobile et Ergonomie**.
Ce projet est développé en kotlin sur Android Studio.
